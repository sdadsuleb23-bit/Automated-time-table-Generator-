# Automated Time Table Generator
Web app that generates a clash-free weekly school timetable[cite: 1, 2].

## Setup
Download `index.html` and double-click to open in any browser.

## Features Done
- Inputs: Classes/sections, subjects, teachers, periods/day, working days[cite: 1, 2]
- Clash-free schedule & max periods per teacher respected[cite: 1, 2]
- View by Class & Teacher + Export to Excel/PDF[cite: 1, 2]

## AI Used
- Tool: Gemini / ChatGPT[cite: 1, 2]
- Prompt: "Create a single-file HTML/JS automated school timetable generator with clash-free scheduling, class/teacher views, and Excel/PDF export."
